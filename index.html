Utility • Universal Python Script

Trainz Universal Asset Fixer

A safe, non-destructive script designed to fix Content Manager errors across TRS19, TRS22, and Trainz Plus.

• Non-Destructive: Creates .bak backups before touching files.
• Dry-Run Mode: Test fixes safely with --dry-run.
• Repairs: VE146 bogeys, missing texture.txt, invalid region strings, and sound stubs.
