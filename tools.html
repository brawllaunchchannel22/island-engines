Trainz Asset Fixer

A Python script that finds and fixes specific Content Manager errors in TRS19, TRS22, and Trainz Plus. Think of it as a targeted repair and warning tool, not a catch-all fixer.

  • 🛡️ Backup first: Creates .bak copies before changing anything — bogey conversions always get their own backup even with --no-backup.
  • 🧪 Dry-run mode: Use --dry-run to preview what would change — nothing is written.
  • 🚂 VE146 — Old bogey tags: Converts legacy root bogey lines to the modern bogeys { } block.
  • 🎨 VE65 — Missing texture stubs: Creates .texture.txt files so the validator stops complaining. Asset may still look wrong without a real texture.
  • 🔊 VE10 / VE103 — Missing sounds: Writes a silent WAV stub. Sound slot is filled but will be silent until replaced.
  • ⚠️ VE179 — Bad region: Warns only — the right region KUID is project-specific and must be set in Content Manager.
  • ⚠️ Brace errors: Warns about mismatched { } — does not auto-"fix", as the correct location can't be guessed.
⚠️ Use at your own risk. Always back up your assets before running any script. While the fixer creates .bak copies automatically, we take no responsibility for data loss or broken assets.
📥 Download (.py)

Requirements

  • Python 3.7 or newer — Windows, Linux, or macOS
  • No extra libraries needed

Usage

  • Auto-detect Trainz folder: python3 trainz_universal_fixer.py
  • Preview only (safe): python3 trainz_universal_fixer.py --dry-run
  • Fix one asset: python3 trainz_universal_fixer.py --path "path/to/asset"
  • Fix whole editing folder: python3 trainz_universal_fixer.py --path "path/to/editing"

What it does NOT fix

VE39 / VE68 (texture sizes), VE13 (category-class), VE48 (trainz-build), VE217 (.m.reflect renaming), and thumbnails are not handled. These require manual editing.

A note on stubs

  • Texture stubs stop the validator error but the asset may still look broken — replace with a real texture when possible.
  • Sound stubs are silent — they exist only to suppress VE10/VE103, not to restore missing audio.
