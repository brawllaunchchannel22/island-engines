Trainz Utility v1.0 • Safe

Trainz Universal Asset Fixer

A safe, non-destructive Python repair utility designed to resolve Content Manager validation and script errors across TRS19, TRS22, and Trainz Plus.

  • 🛡️ 100% Non-Destructive: Creates .bak backups before modifying any configuration.
  • 🧪 Dry-Run Mode: Preview all repairs with --dry-run without touching disk.
  • 🚂 VE146 Bogey Repair: Upgrades legacy root bogey tags into modern bogey containers.
  • 🎨 Textures & Sounds: Generates missing texture.txt and clean sound stubs (VE10/VE65).
  • 💻 Cross-Platform: Works cleanly on Windows, Linux (Steam/Proton), and macOS.
